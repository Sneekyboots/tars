# TARS — Sovereign Memory Protocol

Behavioral twin agent on Solana. Users own their cognitive fingerprint — hashed with Poseidon, tied to their wallet via PDA.

## Stack
- **Anchor 0.32.1** — on-chain program (`anchor/programs/basic/`, crate name `tars`)
- **Next.js 16 + Tailwind CSS** — frontend in `src/`
- **@coral-xyz/anchor ^0.31.1** — TypeScript client
- **@solana/wallet-adapter-react** — Phantom / Backpack wallet connect
- **Anthropic SDK** — behavioral signal extraction via `claude-sonnet-4-20250514`
- **Solana devnet** — deployment target

## Instructions
1. `initialize_twin` — creates PDA `["twin", owner]`
2. `log_decision(decision, context, deviation_score)` — SHA256 hashes + DecisionLog PDA
3. `update_pattern(pattern_vector)` — Poseidon hash → behavioral_hash
4. `verify_deviation(current_pattern)` → u8 deviation score (Manhattan distance)
5. `export_memory` — emits MemoryExported event

## Dev workflow
```bash
# 1. Install Solana toolchain (if not done)
curl -fsSL https://www.solana.new/setup.sh | bash   # installs Superstack skills
sh -c "$(curl -sSfL https://release.solana.com/stable/install)"  # Solana CLI
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust
cargo install --git https://github.com/coral-xyz/anchor avm && avm install 0.32.0

# 2. Frontend
cp .env.example .env.local   # fill in ANTHROPIC_API_KEY
npm install
npm run dev

# 3. Program
cd anchor
anchor build
anchor test
anchor deploy --provider.cluster devnet
```

## Behavioral engine
POST `/api/behavioral/extract` with `{ messages, prev_signals? }`  
Returns `{ signals, pattern_vector }` — 5 dimensions, 0-100 each.

## Accounts
- `TwinAccount` (196 bytes): owner, behavioral_hash[32], pattern_vector[max 10 × u64], decision_count, timestamps
- `DecisionLog` (121 bytes): twin, decision_hash[32], context_hash[32], timestamp, deviation_score
